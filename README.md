# DerivSiteMaker

A trading platform builder for creating and managing professional trading websites. This is a modified version of DerivForge with authentication removed for easier access and deployment.

## Features

- **No Authentication Required**: Direct access to all features without login
- **Trading Platform Builder**: Create custom trading websites
- **Site Management**: Manage multiple trading sites from one dashboard
- **Deployment Tools**: Deploy sites to production
- **Modern UI**: Clean, responsive interface built with Next.js

## Getting Started

1. Clone this repository
2. Open `index.html` in a web browser or serve the files using a web server
3. Start building your trading platforms!

This version has been modified to remove authentication requirements:

- Direct access to dashboard
- Simplified user management
- All features accessible immediately
